# SCT_DA_03 - HR Employee Attrition Dashboard

## Overview

This project focuses on creating an interactive HR Employee Attrition Dashboard using Microsoft Power BI. The dashboard provides insights into employee demographics, attrition trends, departmental performance, and workforce distribution through interactive visualizations and filters.

## Objective

The primary objective of this project is to analyze employee attrition patterns and identify factors that may influence employee turnover within an organization.

## Tools Used

* Microsoft Power BI
* HR Employee Attrition Dataset
* Data Visualization
* Interactive Dashboard Design

## Dataset Information

The dataset contains employee-related information such as:

* Employee Number
* Age
* Gender
* Department
* Job Role
* Monthly Income
* Education Field
* Attrition Status
* Years at Company

## Dashboard Features

### KPI Cards

* Total Employees
* Average Age
* Average Monthly Income

### Visualizations

* Employee Attrition Distribution
* Gender Distribution
* Attrition by Department
* Attrition by Job Role

### Interactive Filters

* Department Filter
* Gender Filter
* Job Role Filter

## Key Insights

* Most employees remain with the organization, while a smaller percentage leave through attrition.
* Research & Development is the largest department in terms of employee count.
* Certain job roles exhibit higher attrition rates compared to others.
* Employee demographics and attrition patterns can be explored interactively using slicers.
* The dashboard enables quick workforce analysis and supports data-driven HR decisions.
